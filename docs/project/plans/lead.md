## 총괄 세션 (계속 이어 쓰는 세션 1개)

**하는 일**: 기능 코드를 직접 짜지 않고 전체를 본다.

| 요청 예 | 하는 일 |
| --- | --- |
| "이번 주 상태 점검" | 열린 PR·CI 결과·브랜치를 훑고 `status.md`의 이번 주 칸을 채움. 일정(overview 주간표)보다 늦은 것 표시 |
| "PR #N 리뷰" | `AGENTS.md` 규칙(가짜 데이터, 자동 확정 금지, 담당 폴더, contracts 준수, 테스트)과 해당 `plans/` 완료 기준으로 검토 → 고칠 점 정리. **승인·merge는 사람이 직접** |
| "이어 붙이기 준비" | 금요일 통합 전에 각자 최신 브랜치로 가짜 메모 하나가 A→B→C→D로 도는지 확인할 순서·명령 정리, 끊기는 곳 기록 |
| "결정 정리" | 대화·PR에서 나온 결정을 `decisions.md`에 추가 제안, 바뀐 내용으로 `overview`·`roles`·`plans` 최신화 |
| "다음 세션 정해줘" | `plans/`에서 지금 할 세션을 골라 "세션 시작 문장"을 만들어 줌 |
| "회사 회신 반영" | 회사가 보낸 자료·답변을 문서에 반영 (`decisions.md` "논의 중" 정리) |
| "멘토링 자료" | 10/23·11/20 멘토링용 진행 요약 |

**세션 시작 문장**
```
나는 개발 총괄이야. 이 세션은 총괄 세션이야. docs/project/plans/lead.md의 "총괄 세션"대로 일해 줘.
기능 코드는 직접 고치지 말고, 상태 점검·PR 리뷰·문서와 결정 정리만 해. 먼저 이번 주 상태 점검부터.
```

- 총괄 세션이 문서를 고칠 땐 `s2/common-docs-…` 브랜치 + PR.
- 대화가 길어지면 새 총괄 세션을 열고 `status.md`부터 읽게 한다 (상태는 대화가 아니라 `status.md`에 남긴다).

**모델 교체 결정은 11/20까지.** 그 뒤에는 새 기능처럼 취급해 바꾸지 않는다.

### 모델 비교·교체 공통 규칙 (L-0 ~ L-4)

1. **바꾸는 건 설정값으로.** 이미 환경 변수로 갈아 끼울 수 있다 — 코드에 모델 이름을 박지 않는다.

   | 부품 | 설정 (`ai-module/app/config.py`) | 쓰는 곳 |
   | --- | --- | --- |
   | LLM | `LLM_PROVIDER`(ollama/openai), `OLLAMA_MODEL`, `OPENAI_MODEL_ANALYSIS`, `OPENAI_MODEL_REPLY`, `OPENAI_MONTHLY_BUDGET_USD` | 메일 분석, 회의록(B), 할 일(C), LLM 직접 판정(B-6) |
   | 개체명 인식 | `GLINER_ENABLED`, `GLINER_MODEL_NAME`, `GLINER_THRESHOLD` | 메일 분석의 인물·회사·제품 추출, A 식별의 입력 |
   | 임베딩 | `EMBEDDING_CLASSIFIER_ENABLED`, `EMBEDDING_MODEL_NAME` | 영업/비영업 분류, A 유사도, C ML-2 특징 |

2. **같은 평가셋, 같은 지표.** 지금 기본값이 기준(baseline). 새 모델은 **기준을 이길 때만** 교체. 지면 기준 유지하고 이유를 남긴다.
3. **지표는 정확도만이 아니다**: 정확도 · 건당 시간 · 메모리/GPU · 비용(유료면 1,000건당 예상) · 실데이터를 외부로 보내는지.
4. **유료 API는 기본값으로 끈다** (AGENTS 규칙 7). OpenAI 비교는 명시적 옵션(`--allow-paid` 같은)과 `--limit`로 소량만, 예산 상한(`OPENAI_MONTHLY_BUDGET_USD`) 안에서. CI·테스트에서는 절대 호출하지 않는다. 키는 환경 변수로만.
5. **외부 API로 실제 데이터를 보내는 운영은 회사 확인 전에는 하지 않는다.** 개발 중 비교는 가짜 데이터로만. 시범 운영의 기본값은 로컬 모델.
6. 결과는 `ai-module/eval/results/`(원자료)와 `ai-module/eval/MODELS.md`(비교표 한 장)에 남기고, 교체하면 `decisions.md`에 한 줄 + 기본값 변경 PR.
7. 다른 사람 부품에 영향을 주는 교체(임베딩 → A·C, NER → A)는 **담당자와 합의 후** 기본값을 바꾼다.

### L-0 모델 비교 틀

- 기존 `ai-module/eval/run_eval.py`(메일 21통, `--engine rule|ollama`)를 넓혀서 **설정 조합을 바꿔 가며** 같은 평가를 돌리고 결과를 한 표로 모으는 도구
  - 대상 과제: 메일 분석(기존 21통), 회의록(B-1 평가셋, 생기면), 개체명(L-3에서 만들 정답), 할 일 분류(C 평가 데이터, 생기면)
  - 기록: 모델 이름·설정, 정확도 지표, 건당 시간, 실행 시각 → `eval/results/*.json`, 요약 → `eval/MODELS.md`
  - 유료 공급자는 옵션을 켜야만 실행, `--limit` 필수
- 테스트: 가짜 provider로 도구 자체가 도는지만 (네트워크 없음)

**세션 시작 문장**
```
나는 개발 총괄이야. docs/project/plans/lead.md의 L-0(모델 비교 틀)을 진행해 줘.
ai-module/eval/run_eval.py, app/config.py, app/llm/을 먼저 읽고, 설정만 바꿔 같은 평가셋을 돌려 결과를 비교표로 모으는 도구를 만들어 줘.
유료 API는 옵션을 켜야만 돌게 하고, 테스트는 네트워크 없이.
```

**세션 시작 문장**

### L-2 LLM 비교·교체

- 후보: 지금 기본값(Ollama `OLLAMA_MODEL`) / 같은 PC에서 돌아가는 다른 로컬 모델 2~3개 (한국어 성능 좋은 것 위주, 크기별) / OpenAI (`OPENAI_MODEL_ANALYSIS`)
- 후보 모델은 그 시점에 **실제로 받을 수 있는지·라이선스·PC 메모리에 올라가는지** 먼저 확인
- 과제별로 따로 판단 (메일 분석은 A 모델, 회의록은 B 모델이 나을 수도 있음 — 과제별 설정이 필요하면 `app/llm/` 수정이라 공용 파일 PR)
- 결과로 정할 것: 시범 운영 기본 모델, OpenAI를 쓸 경우의 조건(회사 확인 필요 사항)

**세션 시작 문장**
```
나는 개발 총괄이야. docs/project/plans/lead.md의 L-2(LLM 비교·교체)를 진행해 줘.
L-0 비교 도구로 지금 기본 로컬 모델, 다른 로컬 후보, OpenAI를 같은 평가셋으로 비교해 줘.
OpenAI는 --limit 10 정도로만, 가짜 데이터로만 돌리고, 결과를 eval/MODELS.md에 표로 정리한 뒤 교체할지 추천해 줘.
```

### L-3 개체명 인식 비교·교체

- 지금: GLiNER (`GLINER_MODEL_NAME`, 기본은 꺼짐)
- 먼저 **정답 데이터**: 가짜 메일·메모에서 사람·회사·직함·제품·날짜를 표시한 평가셋 (A와 같이 쓸 수 있게)
- 후보: 다른 GLiNER 버전, 한국어 개체명 인식으로 학습된 모델, LLM으로 직접 추출, 규칙+사전 조합
- A의 식별 입력이 바뀌므로 교체 전에 A와 합의

**세션 시작 문장**
```
나는 개발 총괄이야. docs/project/plans/lead.md의 L-3(개체명 인식 비교)을 진행해 줘.
app/services/entity_extractor.py와 config의 GLINER 설정을 먼저 읽고, 가짜 메일·메모로 개체명 정답셋을 만든 뒤
지금 GLiNER와 후보 모델들을 L-0 도구로 비교해 줘. 기본값은 바꾸지 말고 추천만.
```

### L-4 임베딩 비교·교체

- 지금: BGE-M3 (`EMBEDDING_MODEL_NAME`)
- A(이름·소속 유사도)와 C(ML-2 특징)가 같이 쓰므로 **두 사람의 평가셋으로** 비교하고, 교체는 합의 후
- 후보: 다국어·한국어 문장 임베딩 모델 중 크기가 비슷하거나 더 작은 것

**세션 시작 문장**
```
나는 개발 총괄이야. docs/project/plans/lead.md의 L-4(임베딩 비교)를 진행해 줘.
embedding_classifier.py와 A·C가 임베딩을 쓰는 곳을 먼저 찾아 읽고, BGE-M3와 후보 모델을 A·C 평가셋으로 비교해 줘. 기본값은 바꾸지 말고 추천만.
```
