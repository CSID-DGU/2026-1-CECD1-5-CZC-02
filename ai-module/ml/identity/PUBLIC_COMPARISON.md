불필요 후보는 **제시 ID 수 기준**이다. 질문 오류율이나 오확정률과 다르다.
오확정 0건은 이번 합성 표본에서의 관측이며 모든 상황의 안전 보장이 아니다.

추가로 찾은 24문항은 등록 별칭 구두점 오타 10건(0→10), 이름 복합 오타·회사 있음 4건(6→10),
이름 복합 오타·회사 없음 10건(0→10)이다. 늘어난 불필요 후보 21개 중 20개는 별칭 구두점 오타,
1개는 회사가 빠진 복합 오타 상황이다. 해당 유형을 지우거나 평균에서 제외하지 않는다.

검증용 140문항에서는 단일 정답 포함이 52/80(65%) → 80/80(100%), 불필요 제시가 30 → 52개다.
최종 시험 10집단을 묶어 5,000회 대응 재표집한 Top-3 포함률 차이의 95% 백분위 구간은
약 **+26.25~+33.75%p**다. 독립 질문 140개인 것처럼 재표집하지 않는다.
이 구간은 같은 합성 생성 규칙의 해당 표본에 한정되며 실제 회사 자료의 구간이 아니다.

## 재현

`ai-module/`에서 기본 테스트 의존성만으로 실행한다. sklearn·모델 학습·LLM·네트워크·DB가 필요 없다.
출력 폴더가 있으면 중단한다. 기존 결과를 덮어쓰거나 Git에 자동 추가하지 않는다.

```bash
python -m ml.identity.public_comparison --output-dir /tmp/identity-public-comparison
python -m pytest ml/identity/test_public_comparison.py -q
```

Windows에서는 출력 경로를 아직 없는 임시 폴더로 바꾼다. 출력 JSON은 UTF-8·LF로 기록한다.
`frozen_protocol.json`, 집합별 `*_dataset.json`, `*_predictions.json`, `report.json`이 생성된다.
전체 자료·예측은 재생성할 수 있어 커밋하지 않고 약 60KB의 요약 보고서만 보관한다.
재현 시 Python 버전·수정한 코드 해시는 달라질 수 있다. 자료의 의미적 해시와 지표를 먼저 비교하고
코드 해시가 달라지면 무엇이 바뀌었는지 확인한다. 기존 보고서의 해시를 새 실행에 맞춰 자동 갱신하지 않는다.

560개 계약 응답을 검사하고 모든 CONFIRMED에 대해 고유한 연락처 일치·충돌 없음·RULE 판정을 별도 검사한다.
hybrid의 경고·폴백이 있으면 정상 비교 결과로 기록하지 않는다. 환경 변수와 입력은 원래대로 유지하고,
실행 전후 코드·모델·입력 자료 해시가 같아야 한다.
