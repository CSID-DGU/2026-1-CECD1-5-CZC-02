# C의 부류 경계 제안 (B·D 교차 검수 전)

공용 task-types.md를 대신하거나 수정하지 않는다. 검토 후 총괄이 공용 문서에 반영할 후보다.

| 경계 | 판단 기준 | 예시 |
| --- | --- | --- |
| MEETING / VISIT | 논의가 핵심이면 미팅, 이동·출입·현장 점검이 핵심이면 방문 | 고객 미팅 안건 준비 / 현장 방문 출입 절차 확인 |
| CONTRACT / DOC | 계약서 작성·송부는 계약 준비, 이미 발송한 서류 회수는 서류 취합 | 계약서 초안 송부 / 서명본 회수 독촉 |
| RENEWAL / MEETING | 계약 만료 대응을 위한 면담이면 만료 면담 | 계약 종료 전 연장 의사 면담 |
| END / RENEWAL | 종료 시 평가 결과물 작성과 만료 전 의사 확인 면담 구별 | 투입 종료 평가 작성 / 계약 만료 대응 면담 |
| SOURCING / PROPOSAL | 후보 찾기와 찾은 후보 제출 구별 | 후보 탐색 시작 / 후보 프로필 전달 |
| REJECTION / NONE | 미채택 결과 전달과 일반 안내 구별 | 탈락 결과 통보 / 설정 안내 메일 |
| PROFITABILITY / CONTRACT | 마진 계산과 계약 문서 준비 구별 | 조건 협의 전 마진 검토 / 계약서 대조 |
| IMPLICIT / NONE | 상대 검토 후 회신 확인만 필요하면 준비 서비스를 억지로 분류하지 않음 | 내부 검토 후 회신 여부 확인 |
| 복수 종류 | 독립 약속은 B에서 항목을 나누는 것이 원칙. 분리되지 않은 복합 항목은 사람이 확인 | 계약서 작성 및 신규 인력 소싱 → 현재 NONE |

이 기준으로 자동 생성한 라벨은 정답 확정본이 아니다. 불일치가 20% 이상인 부류는 정의부터 검토한다.
